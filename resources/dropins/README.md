# Drop-ins

These can be generated by [Packet Analyzer](https://codeberg.org/redstrate/PacketAnalyzer), with [Novus](https://github.com/redstrate/novus) or by manually editing the file.

`appends` is the LGB a drop-in adds to (one of the level's). Where a territory's level isn't known (a duty's own
territory, written without the game's files), it can be `territory/<TerritoryType>` instead: `territory_1049.json`,
Cape Westwind.
